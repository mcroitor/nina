# Архитектура библиотеки NiNa

## 🏗️ Обзор архитектуры

NiNa построена на принципах объектно-ориентированного программирования с четким разделением ответственности между компонентами. Библиотека использует иерархическую структуру от отдельных нейронов до полных нейронных сетей.

## 🧩 Основные компоненты

### 1. 🧠 Cell (Нейрон)

**Назначение**: Базовая единица нейронной сети - отдельный нейрон.

**Ключевые особенности**:

- Хранит веса (DNA) как массив чисел
- Использует активационную функцию для обработки входных данных
- Может мутировать для эволюционного обучения
- Поддерживает сериализацию в JSON

**Основные методы**:

```php
class Cell {
    public function __construct(string $name, array $dna, ?ActivationFunction $activation)
    public function Calculate(array $input): float  // Прямое распространение
    public function CalculateRaw(array $input): float  // Без активации
    public function Born(int $mutationPercent): Cell  // Мутация для эволюции
    public static function Create(string $name, int $size, float $value): Cell
    public function Json(): string
    public static function Load(string $json): Cell
}
```

**Архитектурные принципы**:

- **Инкапсуляция**: Веса и активация скрыты внутри объекта
- **Полиморфизм**: Разные активационные функции через единый интерфейс
- **Валидация**: Проверка входных данных на каждом этапе

### 2. 📊 Layer (Слой)

**Назначение**: Коллекция нейронов, работающих параллельно.

**Ключевые особенности**:

- Содержит массив Cell объектов
- Обрабатывает входные данные через все нейроны
- Возвращает массив выходных значений
- Поддерживает эволюционное размножение

**Основные методы**:

```php
class Layer {
    public function __construct(string $name, array $cells)
    public function Calculate(array $input): array  // Параллельная обработка
    public function Born(int $mutationPercent): Layer  // Эволюция слоя
    public static function Create(int $size): Layer
    public function Json(): string
    public static function Load(string $json): Layer
}
```

**Архитектурные принципы**:

- **Композиция**: Слой состоит из нейронов
- **Единообразие**: Все нейроны в слое имеют одинаковую структуру
- **Параллелизм**: Нейроны обрабатывают данные независимо

### 3. 🌐 Network (Нейронная сеть)

**Назначение**: Полная нейронная сеть из последовательных слоев.

**Ключевые особенности**:

- Последовательное соединение слоев
- Выход одного слоя становится входом следующего
- Автоматическое выравнивание размеров входных данных
- Поддержка сложных архитектур

**Основные методы**:

```php
class Network {
    public function __construct(string $name, array $layers)
    public function Calculate(array $input): array  // Прямое распространение
    public function Born(int $mutationPercent): Network  // Эволюция сети
    public static function Create(string $name, int $layers, int $layerSize): Network
    public function Json(): string
    public static function Load(string $json): Network
}
```

**Архитектурные принципы**:

- **Модульность**: Сеть состоит из независимых слоев
- **Масштабируемость**: Легко добавлять/удалять слои
- **Гибкость**: Поддержка различных архитектур

### 4. 🎯 Trainer (Тренер)

**Назначение**: Эволюционное обучение сетей через генетический алгоритм.

**Ключевые особенности**:

- Управляет популяцией нейронных сетей
- Реализует селекцию лучших экземпляров
- Создает новые поколения через мутации
- Оценивает производительность через фитнес-функцию

**Основные методы**:

```php
class Trainer {
    public function __construct(Network $network, int $populationSize)
    public function Train(string $input, string $expected): void
    public function getBestNetwork(): Network
    public function getNetworks(): array
}
```

**Алгоритм обучения**:

1. **Инициализация**: Создание популяции мутированных сетей
2. **Оценка**: Тестирование каждой сети на тренировочных данных
3. **Селекция**: Выбор лучшей сети по фитнес-функции
4. **Размножение**: Создание нового поколения через мутации
5. **Повторение**: Цикл до достижения желаемой точности

### 5. 🔮 Predictor (Предсказатель)

**Назначение**: Интерфейс для использования обученной сети.

**Ключевые особенности**:

- Простой API для получения предсказаний
- Обработка строковых входных данных
- Преобразование результатов в читаемый формат
- Валидация входных данных

**Основные методы**:

```php
class Predictor {
    public function __construct(Network $network)
    public function Predict(string $input): string
}
```

## 🎯 Принципы проектирования

### 1. **SOLID Principles**

**Single Responsibility**:

- Cell - только вычисления нейрона
- Layer - только управление группой нейронов
- Network - только оркестрация слоев

**Open/Closed**:

- Новые активационные функции через интерфейс
- Новые типы исключений через наследование

**Liskov Substitution**:

- Любая активационная функция взаимозаменяема
- Исключения можно ловить по базовому типу

**Interface Segregation**:

- Минимальные интерфейсы (ActivationFunction)
- Четкое разделение ответственности

**Dependency Inversion**:

- Cell зависит от абстракции ActivationFunction
- Высокоуровневые модули не зависят от низкоуровневых

### 2. **Архитектурные паттерны**

**Composite Pattern**:

- Network состоит из Layer
- Layer состоит из Cell

**Strategy Pattern**:

- Активационные функции как стратегии
- Различные алгоритмы мутации

**Factory Pattern**:

- Create методы для создания объектов
- Загрузка из JSON

**Template Method**:

- Базовая структура обучения в Trainer
- Специфичные реализации в подклассах
