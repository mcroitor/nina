# Custom Exceptions для библиотеки NiNa

## Обзор

Библиотека NiNa использует систему специализированных исключений для обработки различных типов ошибок. Все кастомные исключения наследуются от базового класса `NinaException`, который предоставляет дополнительную функциональность для отладки и логирования.

## Иерархия исключений

```text
NinaException (abstract)
├── NetworkException
├── LayerException  
├── TrainingException
├── SerializationException
├── ComputationException
└── ValidationException
```

## Базовый класс NinaException

Абстрактный базовый класс для всех исключений библиотеки. Предоставляет:

- **Контекст ошибки**: дополнительные данные для отладки
- **Уровень серьезности**: error, warning, critical
- **Детализированные сообщения**: включают контекст
- **Сериализация**: конвертация в массив для логирования

### Основные методы:

- `getContext()`: получить контекст ошибки
- `getSeverity()`: получить уровень серьезности
- `getDetailedMessage()`: получить подробное сообщение с контекстом
- `toArray()`: конвертация в массив

## Специализированные исключения

### 1. NetworkException

- **Назначение**: ошибки уровня сети
- **Коды ошибок**: 1001-1099
- **Основные методы**:
  - `invalidArchitecture()` - неверная архитектура сети
  - `configurationError()` - ошибки конфигурации
  - `incompatibleOperation()` - несовместимые операции

### 2. LayerException

- **Назначение**: ошибки уровня слоев
- **Коды ошибок**: 2001-2099
- **Основные методы**:
  - `invalidSize()` - неверный размер слоя
  - `dimensionMismatch()` - несоответствие размерностей
  - `invalidConnection()` - неверное соединение слоев
  - `operationError()` - ошибки операций слоя

### 3. TrainingException

- **Назначение**: ошибки обучения
- **Коды ошибок**: 3001-3099
- **Основные методы**:
  - `invalidTrainingData()` - неверные тренировочные данные
  - `convergenceError()` - проблемы сходимости
  - `invalidParameters()` - неверные параметры обучения
  - `dataSizeMismatch()` - несоответствие размеров данных
  - `trainingTimeout()` - тайм-аут обучения

### 4. SerializationException

- **Назначение**: ошибки сериализации/десериализации
- **Коды ошибок**: 4001-4099
- **Основные методы**:
  - `fileError()` - ошибки файловых операций
  - `invalidFormat()` - неверный формат данных
  - `versionMismatch()` - несовместимость версий
  - `corruptedData()` - поврежденные данные
  - `jsonError()` - ошибки JSON

### 5. ComputationException

- **Назначение**: ошибки математических вычислений
- **Коды ошибок**: 5001-5099
- **Основные методы**:
  - `domainError()` - ошибки математической области
  - `divisionByZero()` - деление на ноль
  - `matrixError()` - ошибки матричных операций
  - `numericalOverflow()` - числовое переполнение
  - `invalidNumericalValue()` - неверные числовые значения (NaN, Infinity)

### 6. ValidationException

- **Назначение**: ошибки валидации входных данных
- **Коды ошибок**: 6001-6099
- **Уровень серьезности**: warning
- **Основные методы**:
  - `invalidValue()` - неверное значение параметра
  - `outOfRange()` - значение вне диапазона
  - `missingParameter()` - отсутствующий параметр
  - `invalidArraySize()` - неверный размер массива

## Примеры использования

### Базовое использование

```php
try {
    // некоторый код
} catch (NetworkException $e) {
    echo "Network error: " . $e->getMessage();
    print_r($e->getContext());
}
```

### Создание исключений с контекстом

```php
throw NetworkException::invalidArchitecture(
    "Input layer size must be positive",
    ['provided_size' => -5, 'layer_index' => 0]
);
```

### Получение детализированной информации

```php
try {
    // код может выбросить исключение
} catch (NinaException $e) {
    error_log($e->getDetailedMessage());
    
    // Логирование в структурированном виде
    $logData = $e->toArray();
    file_put_contents('error.log', json_encode($logData));
}
```

### Обработка по типу исключения

```php
try {
    $network->train($data);
} catch (TrainingException $e) {
    // Специфическая обработка ошибок обучения
    $this->handleTrainingError($e);
} catch (ValidationException $e) {
    // Обработка ошибок валидации
    $this->handleValidationError($e);
} catch (NinaException $e) {
    // Общая обработка других ошибок библиотеки
    $this->handleGenericError($e);
}
```

## Рекомендации по использованию

1. **Выбор типа исключения**: используйте наиболее специфичный тип исключения для каждой ситуации
2. **Контекст**: всегда добавляйте релевантный контекст для упрощения отладки
3. **Коды ошибок**: используйте предопределенные коды или следуйте установленной схеме нумерации
4. **Обработка**: обрабатывайте исключения от специфичных к общим
5. **Логирование**: используйте `toArray()` для структурированного логирования
