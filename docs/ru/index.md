# Библиотека нейронных сетей NiNa - Документация

Добро пожаловать в документацию библиотеки нейронных сетей NiNa. Эта библиотека предоставляет простую, но мощную PHP реализацию нейронных сетей с обучением генетическим алгоритмом.
