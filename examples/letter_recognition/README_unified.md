# 🧠 NiNa Neural Network - Унифицированная система распознавания буквы "а"

## 📋 Обзор

Эта система демонстрирует 4 различных подхода к обучению нейронных сетей для задачи распознавания буквы "а" на спрайтах 8x8 пикселей. Все подходы используют единую конфигурацию `config.json` и стандартизированный интерфейс.

## 🚀 Доступные алгоритмы

### 1. 🧬 Генетический алгоритм
**Файл:** `letter_recognition.php`  
**Описание:** Эволюционный подход с популяционным поиском оптимальных весов  
**Особенности:** Глобальный поиск, избегает локальных минимумов  
**Время обучения:** Медленное, но устойчивое  

### 2. 🎯 Backpropagation  
**Файл:** `letter_recognition_backprop.php`  
**Описание:** Градиентный метод с прямым и обратным распространением ошибки  
**Особенности:** Быстрая сходимость, требует дифференцируемые функции  
**Время обучения:** Быстрое при хороших начальных условиях  

### 3. 🔄 Гибридный подход  
**Файл:** `letter_recognition_hybrid.php`  
**Описание:** Комбинация GA + Backpropagation (2 этапа)  
**Особенности:** GA находит хорошую стартовую точку, BP дообучает до оптимума  
**Время обучения:** Сбалансированное  

### 4. ⚖️ Многокритериальная оптимизация  
**Файл:** `letter_recognition_multiobjective.php`  
**Описание:** Оптимизация по множественным критериям (точность, устойчивость, простота)  
**Особенности:** Балансирует разные цели одновременно  
**Время обучения:** Длительное, но всесторонний результат  

## 🛠️ Конфигурация

Все параметры настраиваются через файл `config.json`:

```json
{
  "model": {
    "architecture": {
      "layers": 3,
      "layer_size": 64,
      "input_size": 64
    },
    "output": {
      "target_positive": 0.8,
      "target_negative": 0.2,
      "threshold": 0.5
    }
  },
  "dataset": {
    "positive_samples": 20,
    "negative_samples": 15,
    "training_noise_level": 0.05,
    "test_noise_level": 0.1
  },
  "genetic": {
    "population_size": 50,
    "generations": 100,
    "mutation_rate": 0.1,
    "target_fitness": 0.95
  },
  "backpropagation": {
    "learning_rate": 0.01,
    "max_epochs": 100,
    "target_loss": 0.05
  }
}
```

## 🏃‍♂️ Запуск

```bash
# Генетический алгоритм
php letter_recognition.php

# Backpropagation
php letter_recognition_backprop.php

# Гибридный подход
php letter_recognition_hybrid.php

# Многокритериальная оптимизация  
php letter_recognition_multiobjective.php
```

## 🔧 Настройка параметров

### Архитектура сети
- `layers`: количество слоев (по умолчанию: 3)
- `layer_size`: размер каждого слоя (64)
- `input_size`: размер входа (64 для 8×8)

### Обучающие данные  
- `positive_samples`: примеры буквы "а" (20)
- `negative_samples`: примеры НЕ-"а" (15)
- `noise_level`: уровень шума при обучении (5%)

### Генетический алгоритм
- `population_size`: размер популяции (50)
- `generations`: количество поколений (100)
- `mutation_rate`: вероятность мутации (10%)
- `target_fitness`: целевая приспособленность (95%)

### Backpropagation
- `learning_rate`: скорость обучения (0.01)
- `max_epochs`: максимум эпох (100)
- `target_loss`: целевая ошибка (0.05)
